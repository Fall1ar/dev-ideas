# IDEA DECK

Локальная desktop-first программа для личных идей. Добавляй задумки, разбивай их на небольшие шаги, отмечай прогресс и перемещай карточки между входящими, работой и завершённым.

## Запуск на Windows

Распакуй папку и дважды щёлкни по `run-windows.bat` или `index.html`. IDEA DECK откроется в браузере; Python, Node.js, аккаунт и установка зависимостей не нужны. Данные хранятся локально в профиле выбранного браузера на этом компьютере.

## Запуск на macOS или Linux

Открой терминал в папке проекта и выполни:

```sh
./run-local.sh
```

Затем открой `http://127.0.0.1:4173`. Чтобы остановить сервер, нажми `Ctrl+C`.

## Что умеет приложение

- добавлять, редактировать, искать и просматривать идеи;
- вести каждую идею через статусы «Входящие», «В работе», «Готово»;
- раскладывать работу на шаги и отмечать выполненное;
- показывать сводные счётчики, прогресс и приоритет;
- переносить JSON-копию на другое устройство через системное меню «Поделиться» или файл;
- объединять идеи из копии с локальным списком без удаления уже сохранённых карточек.

На первом запуске приложение создаёт три стартовые карточки, заранее подготовленные по заметкам из `IDEAS.md`: Icon Atelier, ToneID и «Песочница-симулятор автоматизации и логистики». Программа не импортирует Markdown автоматически. Рабочие данные хранятся в `localStorage` браузера отдельно на каждом устройстве. При первом открытии обновлённой версии старая карточка «Автономный аванпост» автоматически переименуется и получит новую логистическую концепцию; её статус, приоритет, заметки и пользовательские шаги сохранятся.

### Перенос между устройствами

На исходном устройстве нажми кнопку со стрелкой вниз, чтобы скачать JSON-файл. На телефоне можно нажать кнопку «Поделиться» и отправить файл себе через доступное системное приложение (например, Drive, почту или мессенджер). На принимающем устройстве нажми кнопку со стрелкой вверх и выбери этот JSON-файл. Импорт **объединяет** списки: добавляет новые идеи, совпадающие карточки сопоставляет по ID, берёт более свежие поля и объединяет чек-листы; локальные карточки не удаляются. Для ручной синхронизации в обратную сторону повтори экспорт и импорт уже с другого устройства.

Это перенос файла, а не автоматическая или мгновенная cloud-синхронизация. Если редактировать одну идею на двух устройствах, перенеси обе копии — импорт попробует объединить их, но лучше всё равно проверить карточку после переноса. Удаление идеи не синхронизируется как команда удаления: старая копия из другого устройства может вернуть её при следующем объединении.

Безопасность и приватность: приложение не требует аккаунта, не отправляет идеи на сервер и не загружает внешние шрифты, библиотеки или аналитику. Передача файла выполняется только через выбранное тобой системное приложение. Локальный launcher для macOS/Linux привязывает сервер к `127.0.0.1`.

`IDEAS.md` остаётся читаемым архивом исходных заметок. Новые записи из программы хранятся в браузере; для обмена ими используй экспорт/импорт JSON.

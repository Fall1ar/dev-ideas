# Идеи для разработки

Место для идей приложений и инструментов, которые я захочу попробовать сделать. Первая идея появилась после того, как в LINE X White не нашлись значки для части приложений на моём телефоне.

## ИИ-помощник для создания иконок приложений

**Проблема.** У icon pack’ов тысячи значков, но новые и нишевые приложения всё равно остаются без оформления. Я часто пробую новые приложения, поэтому пробелы замечаю постоянно. А дизайнерам приходится вручную готовить много значков и следить, чтобы каждый подходил к стилю пака.

**Идея.** Сделать ИИ-инструмент, который ускоряет подготовку черновиков иконок, не заменяя финальное решение дизайнера. Пользователь задаёт название приложения или package ID, выбирает icon pack как визуальный ориентир, а система предлагает несколько уникальных черновиков в заданном стиле и собирает их на просмотр.

**Первый прототип (MVP).**
1. Ввести названия нескольких приложений и, если возможно, их официальные страницы или package ID.
2. Задать правила оформления: цвета, толщина линий, размер и формат.
3. Получить по несколько вариантов значка для каждого приложения.
4. Автоматически проверить, что рисунок различим в маленьком размере, ровно центрирован и экспортируется в нужных форматах.
5. Показать варианты дизайнеру для ручного выбора и правок; ничего не публиковать автоматически.

**Возможное продолжение.** Вести список приложений без значков, чтобы не терять запросы; группировать повторы пользователей; готовить аккуратный preview sheet и пакет экспортированных файлов для дизайнера. Подключение к лаунчеру Android можно рассмотреть позднее, только с понятными разрешениями и после проверки спроса.

**Принцип.** ИИ помогает набросать варианты и проверить технические требования, но человек утверждает итог. Нужно использовать законно предоставленные референсы и не выдавать сгенерированный значок за официальный логотип приложения.

**Почему мне интересна эта идея.** Я сам часто устанавливаю новые приложения и вижу эту проблему на своём домашнем экране. Можно начать с личного инструмента, проверить, экономит ли он время, а потом показать прототип разработчикам icon pack’ов.

**Статус:** идея; спрос и способ интеграции с авторами icon pack’ов ещё нужно проверить.
